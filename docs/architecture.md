# Архитектура проекта

Проект Task Manager представляет собой учебное консольное приложение для управления задачами.

## Структура

- `src/` — исходный код приложения;
- `tests/` — автоматизированные тесты;
- `docs/` — документация проекта.

## Основной модуль

Точкой входа в приложение является файл `src/main.js`.

Приложение работает в консольном режиме и принимает команды через аргументы командной строки.

## Тестирование

Автоматизированные тесты располагаются в директории `tests`.
